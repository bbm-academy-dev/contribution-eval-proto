# contribution-eval-proto

Интерактивный инструмент для оценки вклада команды по итогам спринта BBM (двухслойная модель: продукты + glue).

Pure static, без бэкенда и БД. Деплой на Vercel. Каждый спринт — отдельный самодостаточный прогон в своей папке.

## Структура

```
index.html          # хаб — выбор спринта
├── sprint-1/        # архив: пилот OrthoBioSchool, 4 продукта (в оригинале «Забег #1»)
│   ├── index.html      # форма участника
│   ├── aggregate.html  # инструмент фасилитатора
│   ├── js/  css/
└── sprint-2/        # актуальный: 8 участников, 9 продуктов (платформы, контент, GTM, треки)
    ├── index.html
    ├── aggregate.html
    ├── js/  css/
```

Внутри каждой папки:
- `index.html` — форма для участника (заполняется по shared-ссылке от фасилитатора).
- `aggregate.html` — инструмент фасилитатора: setup якоря, круговая диаграмма долей, агрегация результатов.

Новый спринт = скопировать `sprint-2/` в `sprint-3/`, поправить состав (`aggregate.html`) и список продуктов (`js/shared.js`), добавить карточку в корневой `index.html`.

## Локальный запуск

```bash
python -m http.server 4173
```

Открыть `http://127.0.0.1:4173/` (хаб) → выбрать спринт.
